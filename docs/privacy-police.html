Kebijakan Privasi RepoFlow Mobile

Terakhir diperbarui: 13 Agustus 2026

RepoFlow Mobile ("Aplikasi") adalah aplikasi klien GitHub yang memungkinkan pengguna melihat, mengedit, dan mengelola repository GitHub langsung dari perangkat mobile. Kebijakan ini menjelaskan data apa saja yang diproses Aplikasi dan bagaimana data tersebut ditangani.

1. Data yang Diproses Aplikasi

DataDisimpan di manaDikirim ke mana
Personal Access Token GitHub Hanya di perangkat pengguna (terenkripsi, lewat Android Keystore / iOS Keychain) Langsung ke GitHub API (api.github.com) untuk setiap aksi (lihat/edit/commit file) - tidak pernah melewati atau tersimpan di server milik pengembang Aplikasi
Isi repository (nama file, isi file, riwayat commit, dll) Tidak disimpan permanen - diambil langsung dari GitHub API saat dibutuhkan Tetap antara perangkat pengguna dan GitHub API
Preferensi aplikasi (tema, pengaturan tampilan) Hanya di perangkat pengguna (penyimpanan lokal biasa) Tidak dikirim ke mana pun
Data periklanan (identifier perangkat, interaksi iklan) Diproses oleh Google AdMob Google (lihat bagian Pihak Ketiga di bawah)

Penting: Aplikasi ini tidak memiliki server backend milik sendiri yang menyimpan data pengguna. Semua interaksi repository (lihat, edit, commit, buat Pull Request, dll) terjadi langsung antara perangkat pengguna dan GitHub API menggunakan token yang dimasukkan pengguna sendiri. Pengembang Aplikasi tidak memiliki akses ke token atau isi repository pengguna.

2. Pihak Ketiga yang Terlibat

  • GitHub, Inc. - Aplikasi berkomunikasi langsung dengan GitHub REST API untuk semua fitur inti. Penggunaan data oleh GitHub tunduk pada Kebijakan Privasi GitHub.
  • Google AdMob - Aplikasi menampilkan iklan banner dan interstisial melalui Google AdMob. AdMob dapat mengumpulkan identifier perangkat dan data interaksi iklan untuk keperluan penayangan dan personalisasi iklan. Lihat Kebijakan Privasi Google dan bagaimana Google menggunakan data dari partner.

3. Izin yang Digunakan Aplikasi

  • Akses internet - untuk berkomunikasi dengan GitHub API dan menampilkan iklan.
  • Akses penyimpanan/file - untuk memilih file atau arsip ZIP yang akan diunggah ke repository.

Aplikasi tidak meminta akses kamera, mikrofon, lokasi, atau kontak.

4. Keamanan Data

Token GitHub disimpan menggunakan penyimpanan terenkripsi bawaan sistem operasi (Android Keystore / iOS Keychain), bukan penyimpanan biasa yang bisa dibaca aplikasi lain. Pengguna dapat menghapus token kapan saja melalui fitur "Keluar dari Akun" di dalam Aplikasi, yang akan menghapus token tersebut sepenuhnya dari perangkat.

5. Hak Pengguna

  • Pengguna dapat menghapus token GitHub yang tersimpan kapan saja lewat fitur "Keluar dari Akun".
  • Menghapus Aplikasi dari perangkat akan menghapus seluruh data lokal (token, preferensi, cache).
  • Untuk mengontrol data periklanan, pengguna dapat mengatur preferensi iklan lewat pengaturan Google di perangkat masing-masing (Setelan > Google > Iklan).

6. Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah 13 tahun dan tidak secara sengaja mengumpulkan data dari anak-anak.
